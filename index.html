Author

Published

This is an online book used primarily for the course CSA-33706 Ecological Modelling and Data Analysis at Wageningen University. It is also designed for self-study so it may also be useful for people not attending the course.

This book is very much inspired and based on Benjamin Bolker’s book Ecological Models and Data in R. I have mostly switched to more modern R code, drop entirely the Bayesian component and extended hiearchical/multileve models. Note that the style and tone of this book (and all the language errors I have committed) are entirely my own as well as any mistakes and factual errors. The original book has mostly served as guidance for which topics to focus on as we have been teaching our course with Bolker’s book for 15 years. If you really like this topic please consider checking the original book, there are many gems in there that are worth discovering. When I read it as a student it completely changed my mind about statistics, its relationship with modeling (which is my true passion) and has had a big influence on my career so far.

1 How to use this book

Use the sidebar to navigate through the the different parts. The book is structured into Theory, Practicals, Solutions and Supplements. I give some guidance and tips below on how to work through each type of material.

1.1 Theory

This explains the different concepts that the book is set out to explain, organized in chapters. The book is fairly linear: a chapter assumes the content of previous chapters so they should be studied in order. The theory is always supported by examples that include R code and mathematical calculations. I recommend that you type any R code that you see and do the calculations yourself, as switching your brain to “active mode” rather than just reading can help with this type of learning.

There are some short exercises embedded within the text as well as a short quiz. These are meant to be done by yourself the moment they appear. The solutions and (possible) answers are always provided in a collapse box, so that you can check your own answers against them. If the answer does not make sense, or you got really stuck, I would suggest to read the section again, or check the concepts online or with AI, since these exercises and quizzes are meant to be doable if the concepts are understood.

Some definitions, important concepts and potential pitfalls are highlighted in colored boxes. This does not mean that other ideas or concepts in the text are not important, I just want to highlight specific things that I feel are particularly important.

1.2 Practicals and Solutions

For each chapter there are 4 - 8 exercises provided, implementing the skills that were taught in that chapter (plus anything that was already covered in the previous) chapter. The solution to the first exercise (the first two exercises in Chapter 2) is provided for you in detail and it is meant to help further learn the programming component of the course. The solutions for the rest of the exercises are given in the “Solutions” section. As with the exercises within the Theory chapters, please make sure to try the exercise first by yourself before looking at the solution and if you could not do it or do not understand the solution, make sure to go back to the theory or use other sources to understand it.

Chapter 1 is specially since the theory is just a general introduction and overview of the course, so there is no real practice to do. Instead, I provide a thorough crash course to programming in R with most of the skills relevant to the rest of the book (specific methods for modelling and visualization are provided as needed in posterior chapters). I expect three possible starting points for the reader:

  • If you are already fluent in R you can safely skip this practical.

  • If you have some programming in experience with other programming languages (e.g. Python or Matlab) I recommend to go through this practical to make sure that you understadn how to translate the skills you already have to R (which is a rather peculiar language).

  • If you have never programmed, I definetely recommend doing the entire practical but I also suspect you need extra practice and support beyond what this book offers, as some programming literacy is assumed. There are many sources online that teach the level of R required for this course and AI can always be used as a personalised tutor.

1.3 Supplements

Two of the supplements contain reference material containing a long list of distributions and deterministic functions with their properties. These are meant to be supplements to Chapters 2 and 5. A third supplement is a calculus refresher (limits, derivatives and partial derivatives, with practice problems) for readers who need to recall the mathematics used in Chapter 5. A glossary collects the definitions of the main terms of the book.

The remaining supplement describes the R package glmmTMB, where one does not have to write their own likelihood function but rather specify the deterministic component with a formula and select a distribution. It fits linear and generalised linear models, and their mixed-effects versions, which are the models that most statistical books based on R would teach and what many ecologists use. I explain how these models are fitted with the same techniques and concepts as in the rest of the course, by describing the likelihood function that is (implicitly) specified by each formula. My hope is that this allows you to understand better these commonly used models, in case you need to use them or you read a paper that uses them.
