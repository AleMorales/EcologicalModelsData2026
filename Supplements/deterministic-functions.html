Deterministic functions

This document is reference material for the deterministic functions that are used in this book and for several others that are common in ecology. For each function it gives the formula, its properties, R code and a description of when the function is useful. Chapter 5 explains the tools with which the properties are derived (limits, derivatives and special points), so the entries apply these tools without explaining them again.

Every entry has the same parts: a summary of the function, a description of when it is useful and of where it comes from, its formula with the derivation of its landmarks, an example that is calculated by hand and verified in R, a figure and a practice exercise. The numbers in the examples are hypothetical and were chosen so that the calculations can be done by hand.

The symbols are those of Chapter 5. The input is \(x\) and the output is \(y=f(x)\). The parameters are called \(a\), \(b\), \(c\) and \(d\): these letters are positions in a formula, and every entry says what each of them controls and which units it has. Unless an entry says otherwise, the parameters are positive and \(x\ge0\). The R functions use the same letters as the formulas, including c (R keeps functions and other objects apart, so c() still combines values). The papers cited in the entries are listed in Section 8.

2 Polynomials

A polynomial is a sum of powers of \(x\), each multiplied by a parameter. The two polynomials that are used most are the straight line and the parabola.

2.1 Linear

\[ \begin{aligned} \text{R}: &\quad \texttt{a + b * x} \\ \text{Shape}: &\quad \text{straight line} \\ \text{Domain}: &\quad \text{all } x \\ \text{Range}: &\quad \text{all } y \quad (b \neq 0) \\ \text{Parameters}: &\quad a = \text{value at } x = 0 \text{ (units of } y\text{)};\quad b = \text{slope (units of } y \text{ per unit of } x\text{)} \\ \text{At zero}: &\quad f(0) = a,\ \text{slope } b \\ \text{At infinity}: &\quad \text{grows or decreases without bound, slope } b \\ \text{Special}: &\quad \text{crosses zero at } x = -a/b \\ \text{Also written}: &\quad d + b(x - c),\ \text{with } d = a + bc \text{ the value at } x = c \end{aligned} \]

The linear function describes a response that changes by the same amount for every unit of the predictor. It is a mechanistic function when a quantity accumulates or is lost at a constant rate, as the quantity is then a linear function of time. More often it is a phenomenological description over a limited range of \(x\), since any smooth function is close to a straight line over a short enough interval. In this book the linear function is mostly used inside another function: \(e^{a+bx}\) for a positive response and \(\operatorname{logit}^{-1}(a+bx)\) for a probability (see Range and composition).

The function is

\[ f(x)=a+bx, \]

where \(a\) is the value of the function at \(x=0\) (the intercept) and \(b\) is its slope. Both parameters can be positive or negative. The derivative is the same at every \(x\),

\[ f'(x)=b, \qquad f''(x)=0, \]

so the function has neither curvature nor special points. It has no asymptote either: as \(x\to\infty\) it grows without bound when \(b>0\) and decreases without bound when \(b<0\). It crosses zero at \(x=-a/b\), so for a quantity that must be positive the function can only be used on one side of that value.

The intercept \(a\) depends on where the zero of \(x\) lies, and it has no meaning when \(x=0\) is far from the values of interest (e.g., when \(x\) is a calendar year). In that case we write the function around a reference value \(c\) that we choose,

\[ f(x)=d+b(x-c), \qquad d=a+bc, \]

where \(d\) is the value of the function at \(x=c\). This is a reparameterisation: the line is the same, and the slope \(b\) keeps its value and its meaning.

2.1.1 Example: sediment in a pond

Suppose that the layer of sediment at the bottom of a pond was 12 cm thick when monitoring started and that it grows by 0.4 cm/year. With \(x\) the time in years since the start, \(a=12\) cm and \(b=0.4\) cm/year. After 10 years the layer is

\[ f(10)=12+0.4\times10=16 \text{ cm} \]

thick, and it reaches 20 cm when \(12+0.4x=20\), that is, after \(x=(20-12)/0.4=20\) years. Written around year 10, the same line is \(16+0.4(x-10)\). We can verify our math with R:

# Linear function: a is the value at x = 0 and b is the slope
linear = function(x, a = 0, b = 1) {
  a + b * x
}

# Thickness of the sediment after 10 years (cm)
linear(x = 10, a = 12, b = 0.4)
[1] 16
# Years until the layer is 20 cm thick
(20 - 12) / 0.4
[1] 20
# The same line written around year 10, at the start and after 25 years
16 + 0.4 * (c(0, 25) - 10)
[1] 12 22
linear(x = c(0, 25), a = 12, b = 0.4)
[1] 12 22
ImportantPractice: sprint speed of a lizard

The sprint speed of a lizard is 1.2 m/s at a body temperature of 20 °C and 2.0 m/s at 30 °C. Find the parameters \(a\) and \(b\) of the straight line through these two points, with their units. Which speed does the line give at 5 °C, and what does that say about the range of temperatures over which it can be used?

TipSolution

The slope is the change in speed divided by the change in temperature, \(b=(2.0-1.2)/(30-20)=0.08\) m/s/°C. The intercept follows from one of the points: \(a=1.2-0.08\times20=-0.4\) m/s. At 5 °C the line gives \(-0.4+0.08\times5=0\) m/s, and below 5 °C it gives negative speeds. So \(-a/b=5\) °C is the lower end of the range over which this line can describe a speed, and the intercept \(a\) is the value of the line at 0 °C, a temperature at which it is of no use. Written around 20 °C the line is \(1.2+0.08(x-20)\).

2.2 Quadratic

\[ \begin{aligned} \text{R}: &\quad \verb|a + b * x + c * x^2| \\ \text{Shape}: &\quad \text{unimodal when } c < 0;\ \text{U-shaped when } c > 0 \\ \text{Domain}: &\quad \text{all } x \\ \text{Range}: &\quad y \leq a - b^2/(4c) \text{ when } c < 0;\quad y \geq a - b^2/(4c) \text{ when } c > 0 \\ \text{Parameters}: &\quad a = \text{value at } x = 0 \text{ (units of } y\text{)};\quad b = \text{slope at } x = 0;\quad c = \text{half of the second derivative} \\ \text{At zero}: &\quad f(0) = a,\ \text{slope } b \\ \text{At infinity}: &\quad \text{decreases without bound when } c < 0,\ \text{grows without bound when } c > 0 \\ \text{Special}: &\quad \text{maximum or minimum at } x_{\max} = -b/(2c),\ \text{with value } a - b^2/(4c) \\ \text{Also written}: &\quad f(x_{\max}) + c\,(x - x_{\max})^2 \end{aligned} \]

The quadratic function, or parabola, is the simplest function with a maximum or a minimum. It is used as a phenomenological description of a response that is highest at intermediate values of the predictor (e.g., growth as a function of temperature), over a limited range of \(x\). It can also follow from geometry: a process that depends on a surface, such as the area of the skin or of the mouth, is quadratic in the length of the organism. Finally, every smooth function is close to a parabola near its maximum, which is the idea behind the Wald interval of Chapter 4.

Polynomials of a higher order (a cubic function has a term in \(x^3\), and so on) add one bend for every additional power and can follow almost any set of points. However, outside the range of the data they grow or decrease without bound, in a direction that is decided by the highest power alone, so their predictions there are unreliable.1 For that reason this supplement stops at the quadratic function.

The function is

\[ f(x)=a+bx+cx^2, \]

where \(a\) is the value at \(x=0\), \(b\) is the slope at \(x=0\) (in units of \(y\) per unit of \(x\)) and \(c\) controls the curvature (in units of \(y\) per unit of \(x\) squared). The three parameters can be positive or negative. The first two derivatives are

\[ f'(x)=b+2cx, \qquad f''(x)=2c. \]

The second derivative has the same sign everywhere. When \(c<0\) the function is concave for every \(x\) and its only critical point is a maximum; when \(c>0\) it is convex and the critical point is a minimum. Setting \(f'(x)=0\):

\[ x_{\max}=-\frac{b}{2c}, \qquad f(x_{\max})=a-\frac{b^2}{4c}. \]

If we complete the square, we can write the function with these two landmarks as parameters,

\[ f(x)=f(x_{\max})+c\,(x-x_{\max})^2, \]

which shows that the parabola is symmetric around \(x_{\max}\). It also shows that, when \(c<0\), the function crosses zero at \(x_{\max}\pm\sqrt{f(x_{\max})/(-c)}\) and is negative beyond those two values. A response that cannot be negative is therefore described by a quadratic function only between them.

2.2.1 Example: growth of a caterpillar and temperature

Suppose that the growth rate of a caterpillar (mg/day) as a function of temperature \(x\) (°C) is \(f(x)=-6+1.2x-0.03x^2\). The units of the parameters are mg/day for \(a\), mg/day/°C for \(b\) and mg/day/°C² for \(c\). The growth rate is highest at

\[ x_{\max}=-\frac{1.2}{2\times(-0.03)}=20 \text{ °C}, \qquad f(20)=-6+1.2\times20-0.03\times20^2=6 \text{ mg/day}, \]

so the function can be written as \(6-0.03(x-20)^2\). It crosses zero at \(20\pm\sqrt{6/0.03}=20\pm14.1\), that is, at 5.9 and 34.1 °C, and it describes a growth rate only between those temperatures. We can verify our math with R:

# Quadratic function: a is the value at x = 0, b the slope there, c the curvature
quadratic = function(x, a = 0, b = 0, c = 1) {
  a + b * x + c * x^2
}

# Location and value of the maximum from the formulas
-1.2 / (2 * -0.03)
[1] 20
-6 - 1.2^2 / (4 * -0.03)
[1] 6
# The same on a fine grid of temperatures
temperature_grid = seq(0, 40, by = 0.01)
growth_values = quadratic(temperature_grid, a = -6, b = 1.2, c = -0.03)
temperature_grid[which.max(growth_values)]
[1] 20
max(growth_values)
[1] 6
# Temperatures at which the function crosses zero (up to rounding error)
zero_growth = 20 + c(-1, 1) * sqrt(6 / 0.03)
zero_growth
[1]  5.857864 34.142136
quadratic(zero_growth, a = -6, b = 1.2, c = -0.03)

ImportantPractice: species richness and productivity

The number of plant species in a grassland plot as a function of its productivity \(x\) (t/ha/year) is described by \(f(x)=10+4x-0.25x^2\). At which productivity is the number of species highest, and how many species does the function give there? Calculate the slope at \(x=0\) and at \(x=12\), with units. At which productivity does the function return to its value at \(x=0\)?

TipSolution

The maximum is at \(x_{\max}=-4/(2\times(-0.25))=8\) t/ha/year, where the function gives \(10+32-16=26\) species. The derivative is \(f'(x)=4-0.5x\), so the slope is 4 species/(t/ha/year) at \(x=0\) and \(4-6=-2\) species/(t/ha/year) at \(x=12\). The parabola is symmetric around its maximum, so it returns to \(f(0)=10\) species at twice the location of the maximum, \(x=16\) t/ha/year.

3 Piecewise functions

A piecewise function is defined by different formulas on different parts of its domain. The parts meet at a breakpoint, at which the function, its slope or both change abruptly. In R these functions are written with ifelse() (see Functions in R).

3.1 Threshold

\[ \begin{aligned} \text{R}: &\quad \texttt{ifelse(x < c, a, b)} \\ \text{Shape}: &\quad \text{step} \\ \text{Domain}: &\quad \text{all } x \\ \text{Range}: &\quad y = a \text{ or } y = b \\ \text{Parameters}: &\quad a = \text{value below the threshold (units of } y\text{)};\quad b = \text{value from the threshold onwards (units of } y\text{)}; \\ &\quad c = \text{threshold (units of } x\text{)} \\ \text{At the left end}: &\quad f(x) = a,\ \text{slope } 0 \\ \text{At infinity}: &\quad f(x) = b,\ \text{slope } 0 \\ \text{Special}: &\quad \text{jump of size } b - a \text{ at } x = c \\ \text{Also written}: &\quad \text{the limit of } a + \dfrac{b - a}{1 + e^{-s(x - c)}} \text{ as } s \to \infty,\ \text{for } x \neq c \end{aligned} \]

The threshold function describes a response that switches between two levels when the predictor crosses a critical value. It is used when an organism changes its behaviour or its state abruptly, for example the number of eggs that a parasitoid lays on a host as a function of the number of eggs that it carries (Hilborn and Mangel 1997; the original study of Rosenheim and Rosen 1991 used a logistic function), and more generally for the sharp transitions between strategies that models of optimal behaviour predict (Hilborn and Mangel 1997). The function is mechanistic when theory predicts such a switch, and otherwise it is the simplest phenomenological description of two levels. Chapter 8 uses a threshold function to show what a jump does to a likelihood.

The function is

\[ f(x)= \begin{cases} a & \text{if } x<c \\ b & \text{if } x\ge c, \end{cases} \]

where \(a\) and \(b\) are the two levels, which can take any value, and \(c\) is the threshold. The formula has to say to which side the value \(x=c\) belongs; here it belongs to the upper piece. There is nothing to derive with calculus. The two limits are the two levels, and the slope is zero everywhere except at \(x=c\), where the function jumps by \(b-a\) and has no derivative. This has a consequence for estimation: moving \(c\) by a small amount changes the function only if an observation lies between the old and the new threshold, so the methods that search for an optimum by following a slope fail for \(c\) (Chapter 8).

A smooth function that approaches the threshold function is the logistic function with a lower level \(a\),

\[ f(x)=a+\frac{b-a}{1+e^{-s(x-c)}}, \]

where \(s\) is the steepness. The larger \(s\) is, the shorter the range of \(x\) over which the function moves from \(a\) to \(b\), and as \(s\to\infty\) it becomes the threshold function everywhere except at the breakpoint: at \(x=c\) the logistic function equals \((a+b)/2\) for every \(s\), whereas the threshold function equals \(b\).

3.1.1 Example: foraging of bumblebees and temperature

Suppose that the workers of a bumblebee colony stay in the nest below 10 °C and make 6 foraging trips/hour from that temperature onwards. With \(x\) the air temperature, \(a=0\) trips/hour, \(b=6\) trips/hour and \(c=10\) °C. The function gives 0 trips/hour at 8 °C and 6 trips/hour at 10 °C and at 14 °C. A logistic function with a steepness \(s=5\)/°C gives, half a degree below and half a degree above the threshold,

\[ \frac{6}{1+e^{-5\times(9.5-10)}}=\frac{6}{1+e^{2.5}}\approx0.46 \qquad\text{and}\qquad \frac{6}{1+e^{-2.5}}\approx5.54 \]

trips/hour, so it completes most of the switch within one degree. We can verify our math with R:

# Threshold function: a below the threshold c and b from the threshold onwards
threshold = function(x, a = 0, b = 1, c = 1) {
  ifelse(x < c, a, b)
}

# Foraging trips/hour at 8, 10 and 14 degrees
threshold(x = c(8, 10, 14), a = 0, b = 6, c = 10)
[1] 0 6 6
# A logistic function with lower level a, upper level b and steepness s
smooth_threshold = function(x, a = 0, b = 1, c = 1, s = 1) {
  a + (b - a) / (1 + exp(-s * (x - c)))
}

# Half a degree below and above the threshold, for a steepness of 5/°C and of 50/°C
smooth_threshold(x = c(9.5, 10.5), a = 0, b = 6, c = 10, s = 5)
[1] 0.4551491 5.5448509
smooth_threshold(x = c(9.5, 10.5), a = 0, b = 6, c = 10, s = 50)
[1] 8.332766e-11 6.000000e+00

With \(s=50\)/°C the logistic function is indistinguishable from the threshold function at these two temperatures.

ImportantPractice: seedling survival and soil water

The probability that a seedling survives the summer is 0.2 when the water content of the soil is below 15% and 0.9 otherwise. Write this function as a formula and as a call to ifelse(). What is the average survival probability over four plots with a water content of 10, 14, 15 and 22%? What is the slope of the function at 20%?

TipSolution

The function is \(f(x)=0.2\) if \(x<15\) and \(f(x)=0.9\) if \(x\ge15\), that is, ifelse(x < 15, 0.2, 0.9). The four plots have survival probabilities of 0.2, 0.2, 0.9 and 0.9 (the plot at exactly 15% belongs to the upper piece), so the average is \((0.2+0.2+0.9+0.9)/4=0.55\). The slope at 20% is zero: away from the threshold a change in water content has no effect on survival.

3.2 Hockey stick

\[ \begin{aligned} \text{R}: &\quad \texttt{ifelse(x < c, a * x, a * c)} \quad \text{or} \quad \texttt{pmin(a * x, a * c)} \\ \text{Shape}: &\quad \text{saturating, with a sharp corner} \\ \text{Domain}: &\quad \text{all } x \quad (x \geq 0 \text{ in most uses}) \\ \text{Range}: &\quad y \leq ac \\ \text{Parameters}: &\quad a = \text{slope below the breakpoint (units of } y \text{ per unit of } x\text{)};\quad c = \text{breakpoint (units of } x\text{)} \\ \text{At zero}: &\quad f(0) = 0,\ \text{slope } a \\ \text{At infinity}: &\quad f(x) = ac,\ \text{slope } 0 \\ \text{Special}: &\quad \text{breakpoint at } x = c,\ \text{where the slope changes from } a \text{ to } 0 \\ \text{Also written}: &\quad \min(ax, d),\ \text{with } d = ac \text{ the plateau} \end{aligned} \]

The hockey stick function describes a response that increases in proportion to the predictor until it hits a ceiling. It has a mechanistic reading when a process runs at a constant rate per unit of \(x\) until a capacity is reached, as for filter feeders that take up food in proportion to its concentration until they reach a maximum uptake (the Holling type I functional response). It is also used for the number of recruits as a function of the size of the spawning stock in fisheries (Barrowman and Myers 2000), for the density dependence of populations of lemmings, sheep and moose (Framstad et al. 1997; Grenfell et al. 1998; Post et al. 2002; Brännström and Sumpter 2005) and to locate the edges between habitats in a landscape (Toms and Lesperance 2003). Bacon and Watts (1971, 1974) studied how to estimate the transition between two straight lines from data.

The function is

\[ f(x)= \begin{cases} ax & \text{if } x<c \\ ac & \text{if } x\ge c, \end{cases} \]

where \(a\) is the slope of the first piece and \(c\) is the breakpoint. The two pieces meet at \(x=c\), where both give \(ac\), so the function has no jump. Its slope does: the derivative is \(a\) for \(x<c\) and 0 for \(x>c\), and it does not exist at the breakpoint. The plateau \(ac\) can be used as a parameter in the place of the breakpoint, which gives \(\min(ax,d)\) with \(d=ac\): the smaller of the straight line and the plateau, pmin() in R.

It is instructive to compare the hockey stick with the Michaelis–Menten function that has the same initial slope \(a\) and the same upper limit \(ac\), which is \(acx/(c+x)\). At \(x=c\) the hockey stick has reached its plateau, whereas the Michaelis–Menten function is at half of it: the breakpoint of the one is the half-maximum of the other. The two functions are the extremes of a family with a bend of adjustable sharpness, the non-rectangular hyperbola.

3.2.1 Example: uptake of algae by a mussel

Suppose that a mussel clears the algae from 1.5 L/hour of water, up to a concentration of 40 µg/L of carbon, beyond which its uptake stays constant. With \(x\) the concentration of algae (µg/L of carbon) and \(f(x)\) the uptake (µg/hour of carbon), \(a=1.5\) L/hour and \(c=40\) µg/L. The plateau is \(ac=1.5\times40=60\) µg/hour. The uptake is

\[ f(10)=1.5\times10=15, \qquad f(40)=60, \qquad f(100)=60 \]

µg/hour of carbon. The Michaelis–Menten function with the same initial slope and upper limit, \(60x/(40+x)\), gives 12, 30 and 42.9 µg/hour at those concentrations. We can verify our math with R:

# Hockey stick function: slope a up to the breakpoint c, then the plateau a * c
hockey_stick = function(x, a = 1, c = 1) {
  ifelse(x < c, a * x, a * c)
}

# Uptake at 10, 40 and 100 µg/L of carbon
concentrations = c(10, 40, 100)
hockey_stick(x = concentrations, a = 1.5, c = 40)
[1] 15 60 60
# The same with pmin(): the smaller of the line and the plateau
pmin(1.5 * concentrations, 60)
[1] 15 60 60
# Michaelis–Menten function with the same initial slope and upper limit
60 * concentrations / (40 + concentrations)

3.3 Piecewise linear

\[ \begin{aligned} \text{R}: &\quad \texttt{ifelse(x < c, a + b * x, a + b * c + d * (x - c))} \\ \text{Shape}: &\quad \text{two straight lines that meet at a corner} \\ \text{Domain}: &\quad \text{all } x \\ \text{Range}: &\quad \text{all } y \text{ when } b \text{ and } d \text{ have the same sign};\quad y \leq a + bc \text{ when } b > 0 > d \\ \text{Parameters}: &\quad a = \text{value at } x = 0 \text{ (units of } y\text{)};\quad b = \text{slope below the breakpoint (units of } y \text{ per unit of } x\text{)}; \\ &\quad c = \text{breakpoint (units of } x\text{)};\quad d = \text{slope above the breakpoint (units of } y \text{ per unit of } x\text{)} \\ \text{At zero}: &\quad f(0) = a,\ \text{slope } b \quad (c > 0) \\ \text{At infinity}: &\quad \text{grows or decreases without bound, slope } d \\ \text{Special}: &\quad \text{breakpoint at } x = c,\ \text{with value } a + bc,\ \text{where the slope changes from } b \text{ to } d \\ \text{Also written}: &\quad a + bx + (d - b)\max(0,\, x - c) \end{aligned} \]

The piecewise linear function describes a response that changes at one constant rate up to a breakpoint and at another constant rate beyond it. It is the general form of the functions of this group that have no jump: the hockey stick is the case in which the first line starts at zero and the second one is flat. The function is used when an organism is expected to switch from one regime to another at some value of the predictor, for example from growing to reproducing once it has reached a certain size or age, and to locate ecological thresholds in data (Toms and Lesperance 2003). It is mechanistic when theory predicts the switch, and otherwise a phenomenological description of a relationship that bends once.

The function is

\[ f(x)= \begin{cases} a+bx & \text{if } x<c \\ a+bc+d\,(x-c) & \text{if } x\ge c, \end{cases} \]

where \(a\) is the value at \(x=0\), \(b\) is the slope below the breakpoint \(c\) and \(d\) is the slope above it. The parameters \(a\), \(b\) and \(d\) can be positive or negative. The second piece starts at \(a+bc\), which is the value that the first piece reaches at \(x=c\), so the two lines meet and the function has no jump. Its derivative is \(b\) for \(x<c\) and \(d\) for \(x>c\), and it does not exist at the breakpoint. When \(b\) and \(d\) have opposite signs the breakpoint is the maximum (\(b>0>d\)) or the minimum (\(b<0<d\)) of the function, and it is one that we cannot find by setting a derivative to zero.

The function can be written on a single line. The second piece is the first line plus a correction of the slope that applies only beyond the breakpoint,

\[ f(x)=a+bx+(d-b)\max(0,\,x-c), \]

where \(\max(0,x-c)\) is zero up to the breakpoint and equal to the distance from it afterwards (pmax(0, x - c) in R). In this form \(d-b\) is the change in slope at the breakpoint, and a function with several breakpoints is obtained by adding one such term for each of them.

A piecewise linear function with many breakpoints can follow any relationship, at the cost of a corner at each breakpoint. Splines remove the corners: they are piecewise cubic functions whose pieces join smoothly at points called knots. They are used when we want a smooth curve through the data and do not need to interpret its parameters (Wood 2001, 2006), so they are not described further in this supplement.

3.3.1 Example: growth of a fish before and after maturity

Suppose that a fish is 4 cm long when it hatches, grows by 8 cm/year until it matures at an age of 3 years, and by 2 cm/year afterwards, when part of its energy goes to reproduction. With \(x\) the age in years and \(f(x)\) the length in cm, \(a=4\) cm, \(b=8\) cm/year, \(c=3\) years and \(d=2\) cm/year. The length at maturity is \(a+bc=4+8\times3=28\) cm, and

\[ f(2)=4+8\times2=20 \text{ cm}, \qquad f(6)=28+2\times(6-3)=34 \text{ cm}. \]

The fish reaches 40 cm when \(28+2(x-3)=40\), that is, at an age of \(x=3+12/2=9\) years. The change in slope at maturity is \(d-b=-6\) cm/year. We can verify our math with R:

4 Rational functions

A rational function is a ratio of two polynomials. Its limit as \(x\to\infty\) is found by dividing the numerator and the denominator by the highest power of \(x\) (see Limits and asymptotes). Rational functions approach their limits slowly, in proportion to a power of \(x\).

4.1 Hyperbolic

\[ \begin{aligned} \text{R}: &\quad \texttt{a / (b + x)} \\ \text{Shape}: &\quad \text{decreasing, convex} \\ \text{Domain}: &\quad x \geq 0 \\ \text{Range}: &\quad 0 < y \leq a/b \\ \text{Parameters}: &\quad a = \text{numerator (units of } y \text{ times units of } x\text{)};\quad b = \text{value of } x \text{ at which the function has halved (units of } x\text{)} \\ \text{At zero}: &\quad f(0) = a/b,\ \text{slope } -a/b^2 \\ \text{At infinity}: &\quad f(x) \to 0,\ \text{slope} \to 0 \\ \text{Special}: &\quad \text{half of the initial value at } x = b \\ \text{Also written}: &\quad \dfrac{y_0}{1 + x/b},\ \text{with } y_0 = a/b \text{ the value at } x = 0 \end{aligned} \]

The hyperbolic function describes a response that declines towards zero, fast at first and then more and more slowly. It is used for the performance of an individual as a function of the density of its neighbours, for example the number of seeds that a plant produces as a function of the number of plants around it (Pacala and Silander 1987, 1990). The constant \(b\) in the denominator keeps the function finite at \(x=0\), where the simpler form \(a/x\) would be infinite. A mechanistic derivation exists when a total saturates: if the total seed production of a stand follows the Michaelis–Menten function \(ax/(b+x)\) of its density \(x\), the production per plant is that total divided by \(x\), which is \(a/(b+x)\).

The function is

\[ f(x)=\frac{a}{b+x}, \]

where \(b\) has the units of \(x\) and \(a\) has the units of \(y\) multiplied by those of \(x\). At \(x=0\) the function equals \(a/b\), and as \(x\to\infty\) the denominator grows without bound, so \(f(x)\to0\). For large \(x\) the function is close to \(a/x\). Writing it as \(a(b+x)^{-1}\), the power rule and the chain rule give

\[ f'(x)=-\frac{a}{(b+x)^2}, \qquad f''(x)=\frac{2a}{(b+x)^3}. \]

The slope is negative and the second derivative positive for every \(x\ge0\), so the function decreases and is convex everywhere. Its steepest slope is the one at zero, \(-a/b^2\). The parameter \(b\) is a scale parameter (see Half-maxima and characteristic scales): if we solve \(a/(b+x)=a/(2b)\) for \(x\) we find \(x=b\), so \(b\) is the value of \(x\) at which the function has fallen to half of its initial value. In the same way it has fallen to a third at \(x=2b\) and to a quarter at \(x=3b\). Since the value at zero is easier to read from a plot than \(a\), the function is also written as \(y_0/(1+x/b)\) with \(y_0=a/b\).

The total biomass in the pot is \(x\,f(x)=60x/(5+x)\), a Michaelis–Menten function that approaches \(a=60\) g per pot, which gives \(a\) its meaning here: it is the highest biomass that a pot can hold. 4.2 Michaelis–Menten

\[ \begin{aligned} \text{R}: &\quad \texttt{a * x / (b + x)} \\ \text{Shape}: &\quad \text{saturating} \\ \text{Domain}: &\quad x \geq 0 \\ \text{Range}: &\quad 0 \leq y < a \\ \text{Parameters}: &\quad a = \text{asymptote (units of } y\text{)};\quad b = \text{half-maximum (units of } x\text{)} \\ \text{At zero}: &\quad f(0) = 0,\ \text{slope } a/b \\ \text{At infinity}: &\quad f(x) \to a,\ \text{slope} \to 0 \\ \text{Special}: &\quad \text{half-maximum at } x = b \\ \text{Also written}: &\quad \dfrac{\alpha x}{1 + \alpha Hx},\ \text{with } a = 1/H \text{ and } b = 1/(\alpha H) \end{aligned} \]

The Michaelis–Menten function describes a response that increases in proportion to the predictor when the predictor is scarce and levels off when it is abundant, because something else then limits the response. It is one of the two functions of Chapter 5, where its properties are derived step by step, and it has a different name in almost every field that uses it. In biochemistry it is the rate of a reaction catalysed by an enzyme as a function of the concentration of the substrate (Michaelis and Menten 1913), with the parameters written as \(v_{\max}\) and \(K_m\). In microbiology it is the Monod equation for the growth rate of micro-organisms on a limiting nutrient (Monod 1949). In fisheries it is the Beverton–Holt curve for the number of recruits as a function of the size of the spawning stock (Beverton and Holt 1957). In ecology it is best known as the Holling type II functional response, the feeding rate of a predator as a function of the density of its prey (Holling 1959).

The function is mechanistic in each of these uses. Chapter 5 derives it for a predator that divides its time between searching for prey and handling them, and the Beverton–Holt curve follows from a mortality rate of the young fish that increases linearly with their density (Quinn and Deriso 1999). The function is also used phenomenologically for any response that rises from zero and saturates.

The function is

\[ f(x)=\frac{ax}{b+x}, \]

where \(a\) is the asymptote, with the units of \(y\), and \(b\) is the half-maximum, with the units of \(x\). Chapter 5 shows that \(f(0)=0\) and \(f(x)\to a\) as \(x\to\infty\), and that

\[ f'(x)=\frac{ab}{(b+x)^2}, \qquad f''(x)=-\frac{2ab}{(b+x)^3}, \]

so the function increases and is concave for every \(x\ge0\), with an initial slope of \(a/b\). To find the value of \(x\) at which the function reaches a fraction \(p\) of its asymptote we solve \(f(x_p)=pa\):

\[ \begin{aligned} \frac{a\,x_p}{b+x_p} &= pa \\ x_p &= p\,(b+x_p) \\ x_p &= \frac{p}{1-p}\,b . \end{aligned} \]

For \(p=1/2\) this gives the half-maximum, \(x_{1/2}=b\). For \(p=0.9\) it gives \(9b\) and for \(p=0.95\) it gives \(19b\): the function approaches its asymptote slowly, and data that stop at a few times the half-maximum are still far below it.

The parameterisations in use differ in which two landmarks they take as parameters (see Reparameterisation):

Parameters Formula Conversion
Asymptote \(a\) and half-maximum \(b\) \(\dfrac{ax}{b+x}\)
Attack rate \(\alpha\) and handling time \(H\) (Holling type II) \(\dfrac{\alpha x}{1+\alpha Hx}\) \(a=1/H\), \(b=1/(\alpha H)\)
Asymptote \(a\) and initial slope \(s\) \(\dfrac{asx}{a+sx}\) \(s=a/b\)

The attack rate \(\alpha\) of the second form is the initial slope \(s\) of the third one.

4.3 Holling type III

\[ \begin{aligned} \text{R}: &\quad \verb|a * x^2 / (b^2 + x^2)| \\ \text{Shape}: &\quad \text{sigmoid} \\ \text{Domain}: &\quad x \geq 0 \\ \text{Range}: &\quad 0 \leq y < a \\ \text{Parameters}: &\quad a = \text{asymptote (units of } y\text{)};\quad b = \text{half-maximum (units of } x\text{)} \\ \text{At zero}: &\quad f(0) = 0,\ \text{slope } 0 \\ \text{At infinity}: &\quad f(x) \to a,\ \text{slope} \to 0 \\ \text{Special}: &\quad \text{half-maximum at } x = b;\ \text{inflection point at } x = b/\sqrt{3},\ \text{with value } a/4 \\ \text{Also written}: &\quad \dfrac{\alpha x^2}{1 + \alpha Hx^2},\ \text{with } a = 1/H \text{ and } b = 1/\sqrt{\alpha H} \end{aligned} \]

The Holling type III function describes a response that increases slowly when the predictor is scarce, accelerates and then levels off. It is the Michaelis–Menten function with \(x\) replaced by \(x^2\) and the half-maximum by its square, which turns a saturating function into a sigmoid one. As a functional response it describes predators that kill a smaller proportion of the prey when the prey are rare, which can result from predators that switch from rare to common prey, from predators that aggregate where prey are abundant and from other forms of heterogeneity (Morris 1997). A mechanistic derivation exists: if the attack rate of the disc equation is proportional to the density of the prey, \(\alpha x\) in the place of \(\alpha\), the equation becomes \(\alpha x^2/(1+\alpha Hx^2)\).

The function is

\[ f(x)=\frac{ax^2}{b^2+x^2}, \]

where \(a\) is the asymptote, with the units of \(y\), and \(b\) is the half-maximum, with the units of \(x\). At \(x=0\) the function is zero. For small \(x\) the denominator is close to \(b^2\), so \(f(x)\approx(a/b^2)\,x^2\): the function starts as a parabola, with a slope of zero. Dividing the numerator and the denominator by \(x^2\) gives \(a/(b^2/x^2+1)\), which tends to \(a\) as \(x\to\infty\). The quotient rule gives

\[ \begin{aligned} f'(x) &= \frac{2ax\left(b^2+x^2\right)-ax^2\times2x}{\left(b^2+x^2\right)^2} =\frac{2ab^2x}{\left(b^2+x^2\right)^2}, \\ f''(x) &= \frac{2ab^2\left(b^2-3x^2\right)}{\left(b^2+x^2\right)^3}. \end{aligned} \]

The slope is positive for every \(x>0\), so the function increases. The second derivative is zero where \(b^2-3x^2=0\), positive below that value and negative above it, so the inflection point is at

\[ x=\frac{b}{\sqrt{3}}\approx0.58\,b, \qquad f\left(\frac{b}{\sqrt{3}}\right)=\frac{a\,b^2/3}{b^2+b^2/3}=\frac{a}{4}, \]

where the slope has its largest value, \(3\sqrt{3}\,a/(8b)\approx0.65\,a/b\). Unlike the logistic function, the Holling type III function is asymmetric: it is steepest at a quarter of its asymptote.

To find where the function reaches a fraction \(p\) of its asymptote we solve \(x_p^2=p\left(b^2+x_p^2\right)\), which gives

\[ x_p=b\sqrt{\frac{p}{1-p}}. \]

For \(p=1/2\) this is the half-maximum, \(x_{1/2}=b\), and for \(p=0.9\) it is \(3b\), against \(9b\) for the Michaelis–Menten function: the square makes the function approach its asymptote faster. In the form with the attack rate, \(H\) is the handling time and \(\alpha\) has the units of \(y\) per unit of \(x\) squared, with \(a=1/H\) and \(b=1/\sqrt{\alpha H}\).

4.4 Holling type IV

\[ \begin{aligned} \text{R}: &\quad \verb|a * x^2 / (b + c * x + x^2)| \\ \text{Shape}: &\quad \text{sigmoid when } c \geq 0;\ \text{unimodal, with an asymptote, when } c < 0 \\ \text{Domain}: &\quad x \geq 0 \\ \text{Range}: &\quad 0 \leq y < a \text{ when } c \geq 0;\quad 0 \leq y \leq 4ab/(4b - c^2) \text{ when } c < 0 \\ \text{Parameters}: &\quad a = \text{asymptote (units of } y\text{)};\quad b > 0 \text{ (units of } x \text{ squared)};\quad c \text{ (units of } x\text{), with } c^2 < 4b \text{ when } c < 0 \\ \text{At zero}: &\quad f(0) = 0,\ \text{slope } 0 \\ \text{At infinity}: &\quad f(x) \to a,\ \text{from below when } c \geq 0 \text{ and from above when } c < 0 \\ \text{Special}: &\quad \text{when } c < 0,\ \text{maximum at } x = -2b/c \text{ with value } 4ab/(4b - c^2) \\ \text{Also written}: &\quad \text{with } c = 0,\ \text{the Holling type III function } ax^2/(b + x^2) \end{aligned} \]

The Holling type IV function adds a term in \(x\) to the denominator of the Holling type III function, and the sign of its parameter \(c\) decides the shape. When \(c>0\) the function is sigmoid, and it has a mechanistic derivation: it is the functional response of a predator whose attack rate is itself a Michaelis–Menten function of the density of the prey, that is, a predator that pursues prey more actively when they are abundant (Turchin 2003). When \(c<0\) the function rises above its asymptote, reaches a maximum and declines towards the asymptote. In that form it is used phenomenologically for the intake of a consumer that declines at high density, as a result of interference among predators or of defences induced in the prey (Holt 1983; Collings 1997; Wilmshurst et al. 1999; Chen 2004).

The function is

\[ f(x)=\frac{ax^2}{b+cx+x^2}, \]

where \(a\) is the asymptote, \(b\) is positive and has the units of \(x\) squared, and \(c\) has the units of \(x\) and can be positive or negative. Note that \(b\) is here the counterpart of \(b^2\) in the Holling type III function. The limits are found as for that function: \(f(0)=0\) with a slope of zero, since \(f(x)\approx(a/b)\,x^2\) for small \(x\), and \(f(x)\to a\) as \(x\to\infty\), since dividing by \(x^2\) gives \(a/(b/x^2+c/x+1)\). The denominator has to stay positive for every \(x\ge0\). That is always so when \(c\ge0\). When \(c<0\) the denominator is smallest at \(x=-c/2\), where it equals \(b-c^2/4\), so the function requires \(c^2<4b\).

The quotient rule gives a derivative whose numerator simplifies:

\[ \begin{aligned} f'(x) &= \frac{2ax\left(b+cx+x^2\right)-ax^2\left(c+2x\right)}{\left(b+cx+x^2\right)^2} \\ &= \frac{ax\left(2b+cx\right)}{\left(b+cx+x^2\right)^2}. \end{aligned} \]

A quotient is zero only where its numerator is zero (see Maxima and minima), so the critical points are \(x=0\) and the solution of \(2b+cx=0\). When \(c\ge0\) the factor \(2b+cx\) is positive for every \(x\ge0\) and the function increases throughout. When \(c<0\) the slope is positive up to

\[ x_{\max}=-\frac{2b}{c} \]

and negative beyond it, so this is a maximum. Its value follows from substituting \(x_{\max}\) in the function. The denominator is \(b-2b+4b^2/c^2=b\left(4b-c^2\right)/c^2\) and the numerator is \(4ab^2/c^2\), so

\[ f(x_{\max})=\frac{4ab}{4b-c^2}, \]

which is larger than \(a\): the function overshoots its asymptote and returns to it from above. The closer \(c^2\) is to \(4b\), the higher the peak.

Suppose that the intake of a gazelle (g/min of grass) as a function of the biomass of grass \(x\) (g/m²) is \(f(x)=6x^2/(400-20x+x^2)\), so that \(a=6\) g/min, \(b=400\) (g/m²)² and \(c=-20\) g/m². The condition \(c^2<4b\) holds, as \(400<1600\). The intake is highest at

5 Exponential functions

The functions of this group are built from the exponential function \(e^{-bx}\), in which the parameter \(b\) is a rate with the inverse units of \(x\). They approach their limits faster than the rational functions of the same shape, because an exponential dominates any power of \(x\).

5.1 Exponential

\[ \begin{aligned} \text{R}: &\quad \texttt{a * exp(-b * x)} \\ \text{Shape}: &\quad \text{decreasing, convex (decay)};\quad \text{increasing, convex (growth, } ae^{bx}\text{)} \\ \text{Domain}: &\quad x \geq 0 \\ \text{Range}: &\quad 0 < y \leq a \\ \text{Parameters}: &\quad a = \text{value at } x = 0 \text{ (units of } y\text{)};\quad b = \text{rate (inverse units of } x\text{)} \\ \text{At zero}: &\quad f(0) = a,\ \text{slope } -ab \\ \text{At infinity}: &\quad f(x) \to 0,\ \text{slope} \to 0 \\ \text{Special}: &\quad \text{halves every } \log 2/b;\ \text{falls by a factor } e \text{ every } 1/b \\ \text{Also written}: &\quad a\,e^{-x/c} \text{ with } c = 1/b;\quad e^{d - bx} \text{ with } d = \log a \end{aligned} \]

The exponential function describes a quantity that changes by a constant proportion for every unit of the predictor. It is mechanistic whenever the rate of change of a quantity is proportional to the quantity itself: a cohort in which every individual has the same risk of dying per unit of time, litter that loses a constant fraction of its mass per day, or light that loses a constant fraction of its intensity in every layer of leaves of a canopy (Monsi and Saeki 1953). With a positive exponent, \(ae^{bx}\), it describes the growth of a population in which every individual reproduces at a constant rate.

The function is

\[ f(x)=ae^{-bx}, \]

where \(a\) is the value at \(x=0\), since \(e^{0}=1\), and \(b\) is the rate of decline. As \(x\to\infty\), \(e^{-bx}=1/e^{bx}\to0\), so \(f(x)\to0\). The rule for a constant multiple and the rule for the exponential give \(f'(x)=-ab\,e^{-bx}=-b\,f(x)\): the slope is negative for every \(x\), and at any point it is proportional to the value of the function. The second derivative, \(f''(x)=ab^2e^{-bx}\), is positive, so the function is convex.

The function has no special point, and what characterises it is a scale. An increase of \(x\) by one unit multiplies the function by \(e^{-b}\), wherever we start, so a fraction \(1-e^{-b}\) is lost per unit of \(x\). To find the distance over which the function falls to a fraction \(p\) of its value we solve \(e^{-bx}=p\):

\[ x_p=\frac{\log(1/p)}{b}. \]

For \(p=1/2\) this is the half-life \(\log 2/b\approx0.69/b\), for \(p=1/e\) it is the characteristic scale \(1/b\), and for \(p=0.05\) it is \(\log(20)/b\approx3/b\). For exponential growth the same algebra gives the doubling time, \(\log 2/b\).

Taking logarithms gives \(\log f(x)=\log a-bx\): on a plot with a logarithmic \(y\) axis the exponential function is a straight line with slope \(-b\). In the other direction, the exponential of a straight line, \(e^{d-bx}\), is an exponential function with \(a=e^{d}\). This is the form used when the function is the mean of a count, since it is positive for any value of \(d\) and \(b\).

Suppose that the light above a crop is 1500 µmol/m²/s and that it decreases with the leaf area above the point of measurement, \(x\) (m² of leaves per m² of ground, counted from the top of the canopy), as \(f(x)=1500e^{-0.6x}\). 5.2 Saturating exponential

\[ \begin{aligned} \text{R}: &\quad \texttt{a * (1 - exp(-b * x))} \\ \text{Shape}: &\quad \text{saturating} \\ \text{Domain}: &\quad x \geq 0 \\ \text{Range}: &\quad 0 \leq y < a \\ \text{Parameters}: &\quad a = \text{asymptote (units of } y\text{)};\quad b = \text{rate (inverse units of } x\text{)} \\ \text{At zero}: &\quad f(0) = 0,\ \text{slope } ab \\ \text{At infinity}: &\quad f(x) \to a,\ \text{slope} \to 0 \\ \text{Special}: &\quad \text{half-maximum at } x = \log 2/b;\ \text{a fraction } 1 - 1/e \text{ of the asymptote at } x = 1/b \\ \text{Also written}: &\quad d + a\left(1 - e^{-bx}\right),\ \text{which starts at } d \text{ and approaches } d + a \end{aligned} \]

The saturating exponential function describes a response that approaches an upper limit, at a rate that is proportional to the distance that remains to that limit. This is its mechanism, and it appears under several names. It is also called the monomolecular function. In epidemiology it is the catalytic curve, the fraction of a cohort that has been infected by a given age when the risk of infection per unit of time is constant (Anderson and May 1991). It is the simplest form of the von Bertalanffy growth curve (Essington et al. 2001), and it was used by Skellam (1951) for the number of offspring as a function of the number of adults (see also Brännström and Sumpter 2005). In this book it is the response function of the practical of Chapter 6 and of Chapter 7.

The function is

\[ f(x)=a\left(1-e^{-bx}\right), \]

where \(a\) is the asymptote and \(b\) is the rate at which the function approaches it. At \(x=0\) the exponential equals 1 and \(f(0)=0\); as \(x\to\infty\) the exponential tends to zero and \(f(x)\to a\). The derivatives are

\[ f'(x)=ab\,e^{-bx}, \qquad f''(x)=-ab^2e^{-bx}, \]

so the function increases, with an initial slope \(ab\), and is concave everywhere. Note that \(f'(x)=b\left(a-f(x)\right)\): the slope is proportional to the distance to the asymptote. To find where the function reaches a fraction \(p\) of its asymptote we solve \(1-e^{-bx}=p\):

\[ x_p=\frac{\log\left(1/(1-p)\right)}{b}. \]

The half-maximum is \(x_{1/2}=\log 2/b\). At the characteristic scale \(x=1/b\) the function has reached \(1-1/e\approx63\%\) of its asymptote, and it reaches 90% at \(\log(10)/b\approx2.3/b\). A Michaelis–Menten function with the same asymptote and the same initial slope has its half-maximum at \(1/b\) and reaches 90% only at \(9/b\), so the saturating exponential bends more sharply towards its asymptote.

Two shifted and scaled forms of this function are used in later chapters (see Shifting and scaling). The first one adds a value at zero,

\[ f(x)=d+a\left(1-e^{-bx}\right), \]

which starts at \(d\) and approaches \(d+a\); Chapters 6 and 7 write it as \(r+a\left(1-e^{-kx}\right)\) for the response of photosynthesis to light. The second one takes the value at zero, \(y_0\), and the asymptote, \(y_\infty\), as parameters,

\[ f(x)=y_\infty-\left(y_\infty-y_0\right)e^{-bx}, \]

and it is the same function with \(d=y_0\) and \(a=y_\infty-y_0\); the practical of Chapter 7 writes it as \(A-(A-R_0)e^{-kt}\) for the growth of trees.

5.3 Ricker

\[ \begin{aligned} \text{R}: &\quad \texttt{a * x * exp(-b * x)} \\ \text{Shape}: &\quad \text{unimodal} \\ \text{Domain}: &\quad x \geq 0 \\ \text{Range}: &\quad 0 \leq y \leq a/(be) \\ \text{Parameters}: &\quad a = \text{initial slope (units of } y \text{ per unit of } x\text{)};\quad b = \text{rate (inverse units of } x\text{)} \\ \text{At zero}: &\quad f(0) = 0,\ \text{slope } a \\ \text{At infinity}: &\quad f(x) \to 0,\ \text{slope} \to 0 \\ \text{Special}: &\quad \text{maximum at } x = 1/b \text{ with value } a/(be);\ \text{inflection point at } x = 2/b \\ \text{Also written}: &\quad a\,x\,e^{-x/c} \text{ with } c = 1/b;\quad x\,e^{r(1 - x/K)} \text{ with } a = e^{r},\ b = r/K \end{aligned} \]

The Ricker function describes a response that increases in proportion to the predictor when the predictor is small, reaches a maximum and declines towards zero. Ricker (1954) proposed it for the number of recruits of a fish stock as a function of the number of spawners. Its mechanism is a production per individual that declines exponentially with density, \(ae^{-bx}\), so that the total production of \(x\) individuals is \(axe^{-bx}\). In fisheries the decline is attributed to competition among the young fish, for example through cannibalism (Quinn and Deriso 1999), and the same form describes populations in which fecundity falls with density (Hassell 1975; Royama 1992; Brännström and Sumpter 2005). The function is also used phenomenologically for any response that starts at zero, peaks and falls. It is one of the two functions of Chapter 5, where its properties are derived.

The function is

\[ f(x)=axe^{-bx}, \]

where \(a\) is the initial slope and \(b\) is the rate at which the production per individual declines. Chapter 5 shows that

\[ f'(x)=a(1-bx)\,e^{-bx}, \qquad f''(x)=-ab(2-bx)\,e^{-bx}, \]

which gives a maximum at \(x_{\max}=1/b\), with value \(a/(be)\), and an inflection point at \(x=2/b\), where the value is \(2a/(be^2)\) and the decline is steepest. At the maximum the production per individual is \(ae^{-1}\), that is, 37% of what it is at low density.

In population ecology the function is written with a growth rate \(r\) and a carrying capacity \(K\),

\[ f(x)=x\,e^{r(1-x/K)}, \]

which is the form above with \(a=e^{r}\) and \(b=r/K\). In this form \(f(K)=K\): at the carrying capacity the output equals the input. With the location of the peak as a parameter the function is \(axe^{-x/c}\), and the generalised Ricker function takes both the location and the height of the peak as parameters.

5.4 Logistic

\[ \begin{aligned} \text{R}: &\quad \texttt{a / (1 + exp(-b * (x - c)))} \\ \text{Shape}: &\quad \text{sigmoid, symmetric around its midpoint} \\ \text{Domain}: &\quad \text{all } x \\ \text{Range}: &\quad 0 < y < a \\ \text{Parameters}: &\quad a = \text{upper asymptote (units of } y\text{)};\quad b = \text{steepness (inverse units of } x\text{)};\quad c = \text{midpoint (units of } x\text{)} \\ \text{At zero}: &\quad f(0) = a/(1 + e^{bc}) \\ \text{At infinity}: &\quad f(x) \to a \text{ as } x \to \infty;\quad f(x) \to 0 \text{ as } x \to -\infty \\ \text{Special}: &\quad \text{inflection point at } x = c,\ \text{with value } a/2 \text{ and slope } ab/4 \\ \text{Also written}: &\quad \dfrac{e^{\beta_0 + \beta_1 x}}{1 + e^{\beta_0 + \beta_1 x}} \text{ with } a = 1,\ b = \beta_1,\ c = -\beta_0/\beta_1;\quad \dfrac{K}{1 + \frac{K - n_0}{n_0}e^{-rx}} \end{aligned} \]

The logistic function describes a response that increases from a lower to an upper limit, slowly at first, fastest half-way and slowly again. In population ecology it is the size of a population whose growth rate per individual declines linearly with its density, which is its mechanism (see Adler 2004). With an upper asymptote of 1 it is the usual function for a probability that changes with a predictor, and in that role it is phenomenological: it is chosen because it stays between 0 and 1. Verhulst (1838) proposed the curve as a model for the growth of a population and later gave it its name (courbe logistique).

The function is

\[ f(x)=\frac{a}{1+e^{-b(x-c)}}, \]

where \(a\) is the upper asymptote, \(b\) is the steepness and \(c\) is the midpoint. The function is defined for negative values of \(x\) as well, so it has two ends. As \(x\to\infty\), \(e^{-b(x-c)}\to0\) and \(f(x)\to a\). As \(x\to-\infty\) the exponential grows without bound and \(f(x)\to0\). So the function has two asymptotes, 0 and \(a\). At \(x=0\) its value is \(a/(1+e^{bc})\), which is small when \(bc\) is large but is never zero.

For the derivative we write \(f(x)=a\,u^{-1}\) with \(u=1+e^{-b(x-c)}\) and apply the chain rule:

\[ f'(x)=\frac{ab\,e^{-b(x-c)}}{\left(1+e^{-b(x-c)}\right)^2}=b\,f(x)\left(1-\frac{f(x)}{a}\right), \]

where the last equality follows from \(f(x)/a=1/u\) and \(1-f(x)/a=e^{-b(x-c)}/u\). It writes the slope in terms of the function itself, which is convenient: the slope is close to zero where \(f(x)\) is close to 0 or to \(a\), and it is largest in between. If we differentiate \(f'(x)=bf(x)-(b/a)f(x)^2\) once more with the chain rule, we obtain

\[ f''(x)=b\,f'(x)-\frac{2b}{a}\,f(x)\,f'(x)=b\,f'(x)\left(1-\frac{2f(x)}{a}\right). \]

Since \(f'(x)\) is positive everywhere, the second derivative is zero only where \(f(x)=a/2\), which happens at \(x=c\) (there the exponential equals \(e^{0}=1\)). The function is convex before that point and concave after it. So the midpoint \(c\) is the inflection point of the function: the value of \(x\) at which the function reaches half of its asymptote and at which it is steepest. The slope at the midpoint is \(f'(c)=b\,(a/2)(1-1/2)=ab/4\), so for a given asymptote the parameter \(b\) sets the maximum slope. The function is symmetric around its midpoint: \(f(c+s)+f(c-s)=a\) for any distance \(s\).

To find where the function reaches a fraction \(p\) of its asymptote we solve \(f(x_p)=pa\), which gives \(e^{-b(x_p-c)}=(1-p)/p\) and

\[ x_p=c+\frac{1}{b}\log\left(\frac{p}{1-p}\right)=c+\frac{\operatorname{logit}p}{b}. \]

So the function reaches 90% of its asymptote at \(c+\log(9)/b\approx c+2.2/b\) and 10% at \(c-2.2/b\). The distance between these two points, \(4.4/b\), is a convenient way of reading \(b\) from a plot.

The logistic function has three forms that are in common use (see Reparameterisation). The one of this entry has the upper asymptote, the steepness and the midpoint as parameters. Statistical texts write the function with an asymptote of 1 as the inverse logit of a straight line,

\[ f(x)=\frac{1}{1+e^{-(\beta_0+\beta_1x)}}=\frac{e^{\beta_0+\beta_1x}}{1+e^{\beta_0+\beta_1x}}, \]

where \(\beta_0\) is the intercept and \(\beta_1\) the slope of the line. Comparing the exponents, \(\beta_1=b\) and \(\beta_0=-bc\), so the midpoint is \(c=-\beta_0/\beta_1\). In R this form is plogis(beta_0 + beta_1 * x). In population ecology, with time as the input, the function is written as

\[ f(x)=\frac{K}{1+\dfrac{K-n_0}{n_0}\,e^{-rx}}, \]

where \(K\) is the carrying capacity, \(n_0\) is the size of the population at \(x=0\) and \(r\) is its growth rate per individual at low density. In this form the function is the solution of a differential equation for the growth of a population, \(dn/dt=rn(1-n/K)\), which is where the parameters \(r\) and \(K\) come from (this book does not work with dynamical models, so we use the function only as a curve). It is the form of this entry with \(a=K\), \(b=r\) and \(c=\log\left((K-n_0)/n_0\right)/r\). Some texts write the function with the hyperbolic tangent, \(\tfrac{a}{2}\left[1+\tanh\left(b(x-c)/2\right)\right]\), which is again the same curve. A lower asymptote other than zero is obtained by adding a parameter, \(d+a/(1+e^{-b(x-c)})\), as in the threshold entry.

5.5 Gompertz

\[ \begin{aligned} \text{R}: &\quad \texttt{a * exp(-exp(-b * (x - c)))} \\ \text{Shape}: &\quad \text{sigmoid, asymmetric} \\ \text{Domain}: &\quad \text{all } x \\ \text{Range}: &\quad 0 < y < a \\ \text{Parameters}: &\quad a = \text{upper asymptote (units of } y\text{)};\quad b = \text{rate (inverse units of } x\text{)};\quad c = \text{inflection point (units of } x\text{)} \\ \text{At zero}: &\quad f(0) = a\exp\left(-e^{bc}\right) \\ \text{At infinity}: &\quad f(x) \to a \text{ as } x \to \infty;\quad f(x) \to 0 \text{ as } x \to -\infty \\ \text{Special}: &\quad \text{inflection point at } x = c,\ \text{with value } a/e \text{ and slope } ab/e \\ \text{Also written}: &\quad a\exp\left(-d\,e^{-bx}\right) \text{ with } d = e^{bc} \end{aligned} \]

The Gompertz function2 is a sigmoid function like the logistic, with the difference that it is asymmetric: it leaves its lower limit quickly and approaches its upper limit slowly. It is used as an alternative to the logistic function for the growth of organisms and of populations. It can be derived from the assumption that the relative growth rate, \(f'(x)/f(x)\), declines exponentially with \(x\), as we show below. The practical of Chapter 6 compares it with the logistic function.

The function is

\[ f(x)=a\exp\left(-e^{-b(x-c)}\right), \]

where \(a\) is the upper asymptote, \(b\) is a rate and \(c\) is the location of the inflection point. To analyse it we write \(u=e^{-b(x-c)}\), so that \(f(x)=ae^{-u}\). As \(x\to\infty\), \(u\to0\) and \(f(x)\to a\); as \(x\to-\infty\), \(u\) grows without bound and \(f(x)\to0\). The chain rule, with \(du/dx=-bu\), gives

\[ f'(x)=ae^{-u}\times bu=b\,u\,f(x)=b\,f(x)\,\log\left(\frac{a}{f(x)}\right), \]

where the last step uses \(u=-\log\left(f(x)/a\right)\). The relative growth rate is therefore \(f'(x)/f(x)=bu=b\,e^{-b(x-c)}\), an exponential decay. Differentiating once more with the product rule:

\[ f''(x)=b\,f'(x)\log\left(\frac{a}{f(x)}\right)-b\,f'(x) =b\,f'(x)\left[\log\left(\frac{a}{f(x)}\right)-1\right]. \]

Since \(f'(x)\) is positive, the second derivative is zero only where \(\log(a/f(x))=1\), that is, where \(f(x)=a/e\). This happens when \(u=1\), at \(x=c\). So the inflection point is at \(x=c\), where the function has reached \(1/e\approx37\%\) of its asymptote (against 50% for the logistic function) and its slope is \(ab/e\). Half of the asymptote is reached later, where \(u=\log 2\), at \(x=c-\log(\log 2)/b\approx c+0.37/b\).

The function is also written as \(a\exp\left(-d\,e^{-bx}\right)\), with \(d=e^{bc}\). In that form the value at zero is \(ae^{-d}\) and the inflection point is at \(x=\log d/b\).

5.6 Bell-shaped

\[ \begin{aligned} \text{R}: &\quad \verb|a * exp(-(x - c)^2 / (2 * b^2))| \\ \text{Shape}: &\quad \text{unimodal, symmetric} \\ \text{Domain}: &\quad \text{all } x \\ \text{Range}: &\quad 0 < y \leq a \\ \text{Parameters}: &\quad a = \text{height of the peak (units of } y\text{)};\quad b = \text{width (units of } x\text{)};\quad c = \text{location of the peak (units of } x\text{)} \\ \text{At infinity}: &\quad f(x) \to 0 \text{ as } x \to \infty \text{ and as } x \to -\infty \\ \text{Special}: &\quad \text{maximum at } x = c \text{ with value } a;\ \text{inflection points at } x = c \pm b \\ \text{Also written}: &\quad e^{\beta_0 + \beta_1 x + \beta_2 x^2} \text{ with } \beta_2 < 0 \end{aligned} \]

The bell-shaped function, or Gaussian curve, describes a response that is highest at one value of the predictor and declines symmetrically on both sides of it. It is used for the abundance or the performance of a species along an environmental gradient, with the location of the peak as the optimum of the species and the width as its tolerance. It is a phenomenological function. Its formula is that of the probability density of the Normal distribution, multiplied by a constant so that the height of the peak is a parameter; here it describes a curve and the area under it has no role.

The function is

\[ f(x)=a\,e^{-(x-c)^2/(2b^2)}, \]

where \(a\) is the height of the peak, \(c\) its location and \(b\) its width. The parameter \(c\) can take any value. The exponent is zero at \(x=c\), where \(f(c)=a\), and it becomes more and more negative on both sides, so \(f(x)\to0\) as \(x\to\infty\) and as \(x\to-\infty\). The chain rule gives

\[ f'(x)=-\frac{x-c}{b^2}\,f(x), \qquad f''(x)=\left[\frac{(x-c)^2}{b^2}-1\right]\frac{f(x)}{b^2}. \]

The slope is positive for \(x<c\), zero at \(x=c\) and negative for \(x>c\), so the maximum is at \(c\). The second derivative is zero where \((x-c)^2=b^2\): the inflection points are at \(x=c\pm b\), where the function equals \(a\,e^{-1/2}\approx0.61a\). The function is concave between them and convex outside. If we solve \(f(x)=a/2\) we find that the function is at half of its height at \(x=c\pm b\sqrt{2\log 2}\approx c\pm1.18b\).

The logarithm of the function is a parabola, so the function is the exponential of a quadratic function, \(e^{\beta_0+\beta_1x+\beta_2x^2}\) with \(\beta_2<0\) (a composition). Comparing the two forms gives

\[ c=-\frac{\beta_1}{2\beta_2}, \qquad b=\sqrt{-\frac{1}{2\beta_2}}, \qquad a=e^{\beta_0-\beta_1^2/(4\beta_2)}. \]

For a probability, which cannot exceed 1, the corresponding function is the inverse logit of a quadratic function, \(\operatorname{logit}^{-1}\left[d-b(x-c)^2\right]\), which is presented in Chapter 5 and used in the practical of Chapter 6.

6 Functions with a power parameter

In the functions of this group a parameter appears as an exponent. An exponent has no units and changes the shape of a function, which makes these functions flexible. Most of them contain one of the functions of the previous groups as a special case (see Nested functions).

6.1 Power law

\[ \begin{aligned} \text{R}: &\quad \verb|a * x^b| \\ \text{Shape}: &\quad \text{monotonic: increasing when } b > 0,\ \text{decreasing when } b < 0 \\ \text{Domain}: &\quad x > 0 \quad (x \geq 0 \text{ when } b > 0) \\ \text{Range}: &\quad y > 0 \\ \text{Parameters}: &\quad a = \text{value at } x = 1 \text{ (units of } y \text{ per unit of } x^b\text{)};\quad b = \text{exponent (no units)} \\ \text{At zero}: &\quad f(x) \to 0 \text{ when } b > 0;\ \text{grows without bound when } b < 0 \\ \text{At infinity}: &\quad \text{grows without bound when } b > 0;\ f(x) \to 0 \text{ when } b < 0 \\ \text{Special}: &\quad \text{none: multiplying } x \text{ by a factor } m \text{ multiplies } y \text{ by } m^b \text{ everywhere} \\ \text{Also written}: &\quad \log y = \log a + b\log x;\quad y_0\,(x/x_0)^b \text{ with } y_0 = a\,x_0^b \end{aligned} \]

The power law describes a response that changes by a constant proportion when the predictor changes by a constant proportion. It is the function of allometry, the study of how the properties of organisms change with their size: the reproductive biomass of plants as a function of the diameter of their stem (Niklas 1993) and the metabolic rate of animals as a function of their body mass (Etienne et al. 2006) are two examples. It is also used for the number of species as a function of the area sampled (Tjørve 2003) and for the fractal properties of landscapes (Halley et al. 2004). A power law is mechanistic when it follows from geometry (the surface of an organism is proportional to the square of its length and its volume to the cube), and many other mechanisms lead to power laws (Mitzenmacher 2003), so the function alone says little about the process behind it.

The function is

\[ f(x)=ax^{b}, \]

where \(b\) is the exponent, which can be positive or negative, and \(a\) is the value of the function at \(x=1\). The two ends depend on the sign of \(b\). When \(b>0\) the function starts at zero and grows without bound; when \(b<0\) it is unbounded as \(x\to0\) and tends to zero as \(x\to\infty\). The power rule gives

\[ f'(x)=ab\,x^{b-1}=b\,\frac{f(x)}{x}, \qquad f''(x)=ab(b-1)\,x^{b-2}. \]

The function is convex when \(b>1\) or \(b<0\), concave when \(0<b<1\) and a straight line through the origin when \(b=1\). Rearranging the first derivative gives

\[ \frac{f'(x)}{f(x)}=\frac{b}{x}, \]

which says that a small relative change in \(x\) produces a relative change in \(y\) that is \(b\) times as large: an increase of 1% in \(x\) changes \(y\) by about \(b\)%. For a change of any size, \(f(mx)=a(mx)^{b}=m^{b}f(x)\), so multiplying \(x\) by \(m\) multiplies \(y\) by \(m^{b}\), whatever the value of \(x\). It follows that the power law has no characteristic scale and no half-maximum. It has no upper asymptote either; when \(b<0\) it has a horizontal asymptote at zero, which it approaches as \(x\to\infty\). This is the main difference from the exponential function, in which it is a fixed step added to \(x\) that multiplies \(y\) by a constant factor.

Taking logarithms gives \(\log f(x)=\log a+b\log x\): on a plot with two logarithmic axes the power law is a straight line with slope \(b\). The units of \(a\) are awkward, since they depend on \(b\). They become those of \(y\) if we write the function with a reference value \(x_0\) of the predictor,

\[ f(x)=y_0\left(\frac{x}{x_0}\right)^{b}, \qquad y_0=a\,x_0^{b}, \]

where \(y_0\) is the value of the function at \(x=x_0\).

6.2 von Bertalanffy

\[ \begin{aligned} \text{R}: &\quad \texttt{a * (1 - exp(-b * (x - c)))} \\ \text{Shape}: &\quad \text{saturating (simple form)};\quad \text{sigmoid (generalised form)} \\ \text{Domain}: &\quad x \geq c \\ \text{Range}: &\quad 0 \leq y < a \\ \text{Parameters}: &\quad a = \text{asymptotic size (units of } y\text{)};\quad b = \text{growth rate (inverse units of } x\text{)}; \\ &\quad c = \text{value of } x \text{ at which the size is zero (units of } x\text{)} \\ \text{At zero}: &\quad f(0) = a\left(1 - e^{bc}\right),\ \text{slope } ab\,e^{bc} \quad (c \leq 0) \\ \text{At infinity}: &\quad f(x) \to a,\ \text{slope} \to 0 \\ \text{Special}: &\quad \text{half of the asymptote at } x = c + \log 2/b \\ \text{Also written}: &\quad a - (a - y_0)\,e^{-bx} \text{ with } y_0 = a\left(1 - e^{bc}\right);\quad a\left(1 - e^{-b(x-c)}\right)^{1/(1-d)} \text{ (generalised form)} \end{aligned} \]

The von Bertalanffy function describes the size of an organism as a function of its age. It is the usual growth curve in fisheries and it is a mechanistic function (von Bertalanffy 1938): it follows from a balance between the energy that an organism assimilates and the energy that it spends on maintenance (Essington et al. 2001). In its simple form, which is used for body length, it is a saturating exponential function that is shifted along \(x\). In its generalised form, which is used for body mass, the saturating exponential is raised to a power, and the function becomes sigmoid.

The simple form is

\[ f(x)=a\left(1-e^{-b(x-c)}\right), \]

where \(a\) is the asymptotic size, \(b\) is the growth rate and \(c\) is the age at which the function is zero. An organism has a positive size at birth, so \(c\) is zero or negative when \(x\) is the age since birth: it is where the curve would start if we extended it backwards, and it is a location parameter with no biological meaning of its own. The properties are those of the saturating exponential function, moved by \(c\). The size at birth is \(f(0)=a\left(1-e^{bc}\right)\), the function tends to \(a\) as \(x\to\infty\), and its derivative,

\[ f'(x)=ab\,e^{-b(x-c)}=b\left(a-f(x)\right), \]

is positive and decreases with age, so growth is fastest at birth and the function is concave. Half of the asymptotic size is reached at \(x=c+\log 2/b\). Since the size at birth is easier to interpret than \(c\), the function is also written as \(a-(a-y_0)\,e^{-bx}\) with \(y_0=f(0)\).

The generalised form is

\[ f(x)=a\left(1-e^{-b(x-c)}\right)^{1/(1-d)}, \]

where \(d\) is an exponent between 0 and 1, without units. It is the size of an organism that gains mass at a rate proportional to its mass raised to the power \(d\) and loses mass at a rate proportional to its mass; the rate \(b\) is then \(1-d\) times the rate of loss. With \(d=0\) the exponent \(1/(1-d)\) is 1 and we recover the simple form, so the simple form is nested in the generalised one. The value \(d=2/3\) is often used, on the argument that assimilation is proportional to a surface (a length squared) and mass to a volume (a length cubed) (Quinn and Deriso 1999). The exponent is then 3, and the function is the cube of the simple form: if length follows the simple form and mass is proportional to the cube of length, mass follows the generalised form with \(d=2/3\) and the same \(b\) and \(c\).

To find the landmarks of the generalised form we write \(m=1/(1-d)\) and \(u=e^{-b(x-c)}\), so that \(f(x)=a(1-u)^m\) and \(du/dx=-bu\). The chain rule and then the product rule give

\[ \begin{aligned} f'(x) &= abm\,u\,(1-u)^{m-1}, \\ f''(x) &= -ab^2m\,u\,(1-u)^{m-2}\left(1-mu\right). \end{aligned} \]

For \(m>1\) the slope is zero at \(x=c\), where \(u=1\), and the second derivative changes sign where \(u=1/m\). So the generalised form has an inflection point at

\[ x=c+\frac{\log m}{b}, \qquad \text{with value } a\left(1-\frac{1}{m}\right)^{m}=a\,d^{\,1/(1-d)}. \]

For \(d=2/3\) the inflection point is at \(c+\log 3/b\), where the function equals \((2/3)^3a=8a/27\approx0.30\,a\): an organism that follows this function gains mass fastest when it has reached 30% of its final mass.

6.3 Shepherd

\[ \begin{aligned} \text{R}: &\quad \verb|a * x / (b + x^c)| \\ \text{Shape}: &\quad \text{increasing when } c < 1;\ \text{saturating when } c = 1;\ \text{unimodal when } c > 1 \\ \text{Domain}: &\quad x \geq 0 \\ \text{Range}: &\quad y \geq 0;\quad 0 \leq y < a \text{ when } c = 1 \\ \text{Parameters}: &\quad a \text{ (units of } y \text{ times units of } x^{c-1}\text{)};\quad b \text{ (units of } x^c\text{)};\quad c = \text{exponent (no units)} \\ \text{At zero}: &\quad f(0) = 0,\ \text{slope } a/b \\ \text{At infinity}: &\quad \text{grows without bound when } c < 1;\ f(x) \to a \text{ when } c = 1;\ f(x) \to 0 \text{ when } c > 1 \\ \text{Special}: &\quad \text{when } c > 1,\ \text{maximum at } x = \left(b/(c-1)\right)^{1/c} \\ \text{Also written}: &\quad \dfrac{sx}{1 + (x/k)^c},\ \text{with } s = a/b \text{ and } k = b^{1/c} \end{aligned} \]

The Shepherd function is a Michaelis–Menten function in which the \(x\) of the denominator is raised to a power. It is used for the output of a population (recruits, seeds, the adults of the next generation) as a function of its density, when the strength of the competition among individuals is to be estimated from the data (Maynard Smith and Slatkin 1973; Brännström and Sumpter 2005). The exponent \(c\) sets that strength. With \(c=1\) the function is the Michaelis–Menten function and the output levels off. With \(c<1\) the output keeps increasing with density, and with \(c>1\) it declines at high density, as it does for the Ricker function; population ecologists call the two cases undercompensating and overcompensating density dependence. In fisheries the function generalises the Beverton–Holt curve, and it can be derived from a mortality of the young fish that depends on the initial size of their cohort (Quinn and Deriso 1999).

The function is

\[ f(x)=\frac{ax}{b+x^{c}}, \]

where \(c\) is the exponent and \(a\) and \(b\) are positive. The units of \(a\) and \(b\) depend on \(c\), which makes them hard to interpret, so we first look for landmarks. For small \(x\) the term \(x^c\) is negligible next to \(b\) and \(f(x)\approx(a/b)\,x\): the initial slope is \(a/b\). For large \(x\) the term \(b\) is negligible next to \(x^c\) and \(f(x)\approx ax^{1-c}\), which grows without bound when \(c<1\), equals \(a\) when \(c=1\) and tends to zero when \(c>1\). The quotient rule gives

\[ f'(x)=\frac{a\left(b+x^{c}\right)-ax\times cx^{c-1}}{\left(b+x^{c}\right)^2} =\frac{a\left[b-(c-1)\,x^{c}\right]}{\left(b+x^{c}\right)^2}. \]

When \(c\le1\) the numerator is positive for every \(x\) and the function increases throughout. When \(c>1\) the numerator is zero where \(x^c=b/(c-1)\), so the function has a maximum at

\[ x_{\max}=\left(\frac{b}{c-1}\right)^{1/c}, \qquad f(x_{\max})=\frac{a\,(c-1)}{bc}\,x_{\max}, \]

where the value follows from replacing \(x^c\) by \(b/(c-1)\) in the denominator.

The function is easier to read with the initial slope \(s=a/b\) and the scale \(k=b^{1/c}\) as parameters, which we obtain by dividing the numerator and the denominator by \(b\):

\[ f(x)=\frac{sx}{1+(x/k)^{c}}. \]

In this reparameterisation \(k\) has the units of \(x\) and \(s\) those of \(y\) per unit of \(x\). At \(x=k\) the denominator equals 2 whatever the value of \(c\), so \(k\) is the density at which the output is half of what the initial slope alone would give, \(sk/2\). The exponent then decides what happens beyond \(k\), and the maximum for \(c>1\) is at \(k\,(c-1)^{-1/c}\).

6.4 Hassell

\[ \begin{aligned} \text{R}: &\quad \verb|a * x / (b + x)^c| \\ \text{Shape}: &\quad \text{increasing when } c < 1;\ \text{saturating when } c = 1;\ \text{unimodal when } c > 1 \\ \text{Domain}: &\quad x \geq 0 \\ \text{Range}: &\quad y \geq 0;\quad 0 \leq y < a \text{ when } c = 1 \\ \text{Parameters}: &\quad a \text{ (units of } y \text{ times units of } x^{c-1}\text{)};\quad b \text{ (units of } x\text{)};\quad c = \text{exponent (no units)} \\ \text{At zero}: &\quad f(0) = 0,\ \text{slope } a/b^c \\ \text{At infinity}: &\quad \text{grows without bound when } c < 1;\ f(x) \to a \text{ when } c = 1;\ f(x) \to 0 \text{ when } c > 1 \\ \text{Special}: &\quad \text{when } c > 1,\ \text{maximum at } x = b/(c-1) \text{ and inflection point at } x = 2b/(c-1) \\ \text{Also written}: &\quad \dfrac{sx}{(1 + x/b)^c},\ \text{with } s = a/b^c \text{ the initial slope} \end{aligned} \]

The Hassell function is a Michaelis–Menten function in which the whole denominator is raised to a power. Hassell (1975) proposed it for the density dependence of populations with one generation per year, and it is used in the same way as the Shepherd function, from which it differs in where the exponent is placed (see also Brännström and Sumpter 2005). The exponent \(c\) again sets the strength of the competition: the output keeps increasing with density when \(c<1\), levels off when \(c=1\) and declines at high density when \(c>1\). The function is mostly used phenomenologically, to let the data decide among these three cases.

The function is

\[ f(x)=\frac{ax}{(b+x)^{c}}, \]

where \(c\) is the exponent, \(b\) has the units of \(x\) and \(a\) has units that depend on \(c\). For small \(x\) the denominator is close to \(b^c\), so the initial slope is \(a/b^c\). For large \(x\) the denominator is close to \(x^c\) and \(f(x)\approx ax^{1-c}\), which gives the same three cases as for the Shepherd function. The quotient rule, with the chain rule for the denominator, gives

\[ \begin{aligned} f'(x) &= \frac{a\,(b+x)^{c}-ax\times c\,(b+x)^{c-1}}{(b+x)^{2c}} =\frac{a\left[b-(c-1)\,x\right]}{(b+x)^{c+1}}, \\ f''(x) &= \frac{ac\left[(c-1)\,x-2b\right]}{(b+x)^{c+2}}. \end{aligned} \]

When \(c\le1\) the slope is positive for every \(x\). When \(c>1\) the numerator of the first derivative is zero at

\[ x_{\max}=\frac{b}{c-1}, \qquad f(x_{\max})=\frac{a\,(c-1)^{c-1}}{c^{\,c}\,b^{\,c-1}}, \]

which is a maximum, and the numerator of the second derivative is zero at \(x=2b/(c-1)\), an inflection point on the way down. As for the Ricker function, the inflection point is at twice the location of the maximum. The value of the maximum follows from \(b+x_{\max}=bc/(c-1)\); for \(c=2\) it is \(a/(4b)\) and for \(c=3\) it is \(4a/(27b^2)\).

The resemblance to the Ricker function has a reason. With the initial slope as a parameter the function is

\[ f(x)=\frac{sx}{(1+x/b)^{c}}, \qquad s=\frac{a}{b^{c}}, \]

and if we let \(c\) grow while we keep the ratio \(c/b\) at a fixed value \(\beta\), the term \((1+\beta x/c)^{-c}\) tends to \(e^{-\beta x}\). So the Hassell function has the Michaelis–Menten function at one end of its range (\(c=1\)) and approaches the Ricker function \(sxe^{-\beta x}\) at the other.

6.5 Generalised Ricker

\[ \begin{aligned} \text{R}: &\quad \verb|a * ((x / b) * exp(1 - x / b))^c| \\ \text{Shape}: &\quad \text{unimodal, of adjustable width} \\ \text{Domain}: &\quad x \geq 0 \\ \text{Range}: &\quad 0 \leq y \leq a \\ \text{Parameters}: &\quad a = \text{height of the peak (units of } y\text{)};\quad b = \text{location of the peak (units of } x\text{)};\quad c = \text{exponent (no units)} \\ \text{At zero}: &\quad f(0) = 0;\ \text{slope } 0 \text{ when } c > 1,\ ae/b \text{ when } c = 1 \\ \text{At infinity}: &\quad f(x) \to 0,\ \text{slope} \to 0 \\ \text{Special}: &\quad \text{maximum at } x = b \text{ with value } a;\ \text{inflection points at } x = b\left(1 \pm 1/\sqrt{c}\right) \text{ (only the upper one when } c \leq 1\text{)} \\ \text{Also written}: &\quad a'x^{c}e^{-cx/b} \text{ with } a' = a\,(e/b)^{c};\quad \text{with } c = 1,\ \text{the Ricker function } (ae/b)\,x\,e^{-x/b} \end{aligned} \]

The generalised Ricker function describes a response with a single peak whose location, height and width are three separate parameters. In the Ricker function one parameter controls both where the peak is and how fast the function declines beyond it, so a peak that is far from zero is necessarily wide; the exponent of the generalised function removes that link. Persson et al. (1998) used it for the attack rate of a predator as a function of its body mass, and in fisheries it has been proposed for the number of recruits as a function of the size of the spawning stock (Quinn and Deriso 1999). It is a phenomenological function. Chapter 5 uses it for the number of tadpoles killed as a function of their body length. Bellows (1981) proposed another generalisation of the Ricker function, in which the power is placed inside the exponential.

The function is

\[ f(x)=a\left[\frac{x}{b}\,e^{1-x/b}\right]^{c}, \]

where \(a\) is the height of the peak, \(b\) is its location and \(c\) is a positive exponent. The term in brackets is a Ricker function that is written so that its maximum is at \(x=b\) and has a value of 1. The function is zero at \(x=0\), and it tends to zero as \(x\to\infty\) because the exponential dominates the power of \(x\). The derivative is easiest to find from the logarithm of the function, \(\log f(x)=\log a+c\left[\log(x/b)+1-x/b\right]\), whose derivative is \(f'(x)/f(x)\):

\[ f'(x)=c\,f(x)\left(\frac{1}{x}-\frac{1}{b}\right). \]

The slope is positive for \(x<b\), zero at \(x=b\) and negative for \(x>b\), whatever the value of \(c\): the maximum is at \(x=b\), where the term in brackets equals 1 and \(f(b)=a\). Differentiating once more with the product rule gives

\[ f''(x)=c\,f(x)\left[c\left(\frac{1}{x}-\frac{1}{b}\right)^{2}-\frac{1}{x^{2}}\right], \]

which is zero where \(\sqrt{c}\,\left|1-x/b\right|=1\). So the inflection points are at

\[ x=b\left(1\pm\frac{1}{\sqrt{c}}\right), \]

one on each side of the peak when \(c>1\). The distance between them, \(2b/\sqrt{c}\), is a measure of the width of the peak: a peak that is half as wide needs an exponent that is four times as large. When \(c\le1\) the lower value is zero or negative and is not an inflection point (with \(c=1\) it is \(x=0\), where the second derivative is \(-2ae/b^2\) and not zero), so the only inflection point is the upper one. With \(c=1\) it is at \(2b\), as for the Ricker function. Near its peak the function is close to the bell-shaped function with height \(a\), location \(b\) and width \(b/\sqrt{c}\).

With \(c=1\) the function is \((ae/b)\,xe^{-x/b}\), a Ricker function with an initial slope \(ae/b\) and a rate \(1/b\). For any \(c\) the function can be multiplied out to \(a'x^{c}e^{-cx/b}\) with \(a'=a\,(e/b)^{c}\), a power of \(x\) multiplied by an exponential, which is the form in which it is often printed.

These are the values that we would use as starting values when fitting the function to the data (see Starting values by eye).

6.6 Non-rectangular hyperbola

\[ \begin{aligned} \text{R}: &\quad \verb|(s + p_max - sqrt((s + p_max)^2 - 4 * theta * s * p_max)) / (2 * theta)|,\ \text{with } \texttt{s = alpha * x} \\ \text{Shape}: &\quad \text{saturating, with a bend of adjustable sharpness} \\ \text{Domain}: &\quad x \geq 0 \\ \text{Range}: &\quad 0 \leq y < p_{\max} \\ \text{Parameters}: &\quad \alpha = \text{initial slope (units of } y \text{ per unit of } x\text{)};\quad p_{\max} = \text{asymptote (units of } y\text{)}; \\ &\quad \theta = \text{sharpness of the bend (no units)},\ 0 < \theta \leq 1 \\ \text{At zero}: &\quad f(0) = 0,\ \text{slope } \alpha \\ \text{At infinity}: &\quad f(x) \to p_{\max},\ \text{slope} \to 0 \\ \text{Special}: &\quad \text{at } x = p_{\max}/\alpha \text{ the function equals } p_{\max}/\left(1 + \sqrt{1 - \theta}\right) \\ \text{Also written}: &\quad \text{the smaller root } y \text{ of } \theta y^2 - (\alpha x + p_{\max})\,y + \alpha x\,p_{\max} = 0 \end{aligned} \]

The non-rectangular hyperbola describes the rate of photosynthesis of a leaf as a function of the light that it receives. It is a saturating function with three parameters: the initial slope, the asymptote and the sharpness of the bend between the two. It is derived from principles of plant physiology (Thornley 2002), so it is a mechanistic function, and its parameters have their own symbols in that field: \(\alpha\) is the efficiency with which the leaf uses light when light is scarce, \(p_{\max}\) is the rate of photosynthesis when light is abundant and \(\theta\) is the sharpness. We keep these symbols here. In the terms of the Michaelis–Menten function, \(p_{\max}\) is the asymptote \(a\) and \(\alpha\) is the initial slope \(a/b\).

The function is

\[ f(x)=\frac{\alpha x+p_{\max}-\sqrt{\left(\alpha x+p_{\max}\right)^2-4\,\theta\,\alpha x\,p_{\max}}}{2\,\theta}, \]

where \(x\) is the light received by the leaf. The formula is the smaller of the two solutions of a quadratic equation in \(y=f(x)\),

\[ \theta\,y^2-\left(\alpha x+p_{\max}\right)y+\alpha x\,p_{\max}=0, \]

and the properties of the function are easier to derive from this equation than from the formula. If we move the term \((1-\theta)\,y^2\) to the right-hand side, the left-hand side can be factorised:

\[ \left(\alpha x-y\right)\left(p_{\max}-y\right)=(1-\theta)\,y^2 . \]

The two factors on the left are the distances from \(y\) to the straight line \(\alpha x\) and to the plateau \(p_{\max}\). This form shows the two extremes of the function. When \(\theta=1\) the right-hand side is zero, so one of the two factors has to be zero: \(y\) is either on the line or on the plateau, and the smaller root is \(\min(\alpha x,p_{\max})\), a hockey stick function with a breakpoint at \(x=p_{\max}/\alpha\). When \(\theta=0\) the quadratic term of the equation vanishes and what remains is \(\alpha x\,p_{\max}=\left(\alpha x+p_{\max}\right)y\), that is,

\[ y=\frac{\alpha x\,p_{\max}}{\alpha x+p_{\max}}=\frac{p_{\max}\,x}{p_{\max}/\alpha+x}, \]

a Michaelis–Menten function with an asymptote \(p_{\max}\) and a half-maximum \(p_{\max}/\alpha\). (The formula itself cannot be evaluated at \(\theta=0\), as it divides by zero; the Michaelis–Menten function is its limit as \(\theta\to0\).) Both functions are therefore nested in the non-rectangular hyperbola, and values of \(\theta\) between 0 and 1 give curves between them.

The limits follow from the same form. At \(x=0\) the equation is satisfied by \(y=0\). For small \(x\) and \(y\), the term \(y^2\) is negligible and \(p_{\max}-y\approx p_{\max}\), so \(y\approx\alpha x\): the initial slope is \(\alpha\) for every \(\theta\). Dividing both sides by \(\alpha x\) gives \((1-y/(\alpha x))(p_{\max}-y)=(1-\theta)\,y^2/(\alpha x)\), whose right-hand side tends to zero as \(x\to\infty\) since \(y\) stays below \(p_{\max}\), so \(f(x)\to p_{\max}\).

The parameter \(\theta\) can be read at one particular value of \(x\). At \(x=p_{\max}/\alpha\), where the line \(\alpha x\) crosses the plateau, the equation becomes \(\theta y^2-2p_{\max}\,y+p_{\max}^2=0\), and its smaller root is

\[ f\left(\frac{p_{\max}}{\alpha}\right)=\frac{p_{\max}\left(1-\sqrt{1-\theta}\right)}{\theta} =\frac{p_{\max}}{1+\sqrt{1-\theta}} . \]

At this value of \(x\) the function is at half of its asymptote when \(\theta=0\), at two thirds when \(\theta=0.75\) and on the asymptote when \(\theta=1\). The sharpness is hard to estimate from data (Thornley 2002), because it only affects the function around the bend.

Leaves also respire, so that their net exchange of carbon dioxide is negative in the dark. This is described by subtracting the rate of respiration from the function, which is a shift along \(y\).

6.7 Richards

\[ \begin{aligned} \text{R}: &\quad \verb|a / (1 + d * exp(-b * (x - c)))^(1 / d)| \\ \text{Shape}: &\quad \text{sigmoid, of adjustable asymmetry} \\ \text{Domain}: &\quad \text{all } x \text{ when } d > 0;\quad x \geq c + \log(-d)/b \text{ when } -1 \leq d < 0 \\ \text{Range}: &\quad 0 < y < a \\ \text{Parameters}: &\quad a = \text{upper asymptote (units of } y\text{)};\quad b = \text{rate (inverse units of } x\text{)}; \\ &\quad c = \text{inflection point (units of } x\text{)};\quad d = \text{shape (no units)},\ d \geq -1,\ d \neq 0 \\ \text{At zero}: &\quad f(0) = a/\left(1 + d\,e^{bc}\right)^{1/d} \\ \text{At infinity}: &\quad f(x) \to a \text{ as } x \to \infty;\quad f(x) \to 0 \text{ as } x \to -\infty \text{ when } d > 0 \\ \text{Special}: &\quad \text{inflection point at } x = c,\ \text{with value } a\,(1 + d)^{-1/d} \text{ and slope } ab\,(1 + d)^{-1/d - 1} \\ \text{Also written}: &\quad \text{logistic } (d = 1);\ \text{Gompertz } (d \to 0);\ \text{saturating exponential } (d = -1) \end{aligned} \]

The Richards function is a family of growth curves with an upper asymptote, in which a fourth parameter sets how asymmetric the curve is. Richards (1959) proposed it as a flexible function for the growth of plants, and it is used when neither the logistic nor the Gompertz function describes the data well, for example for the growth of individual plants (Damgaard et al. 2002). Its interest for this book is that it contains several of the functions of this supplement as special cases (Haefner 1996; Damgaard et al. 2002), so it shows how they are related. In general it is a phenomenological function, although particular values of the shape parameter give functions that have a mechanism. Other generalisations of the logistic function exist: Emlen (1996) raised \(x\) to a power inside the exponential, and Schnute (1981) proposed a growth function that is more general still.

The function is

\[ f(x)=\frac{a}{\left[1+d\,e^{-b(x-c)}\right]^{1/d}}, \]

where \(a\) is the upper asymptote, \(b\) is a rate, \(c\) is the location of the inflection point and \(d\) is the shape parameter. As for the Gompertz function we write \(u=e^{-b(x-c)}\), so that \(f(x)=a\,(1+du)^{-1/d}\). As \(x\to\infty\), \(u\to0\) and \(f(x)\to a\). When \(d>0\), \(u\) grows without bound as \(x\to-\infty\) and \(f(x)\to0\). When \(d\) is negative the term \(1+du\) reaches zero at \(u=-1/d\), so the function starts from zero at \(x=c+\log(-d)/b\) and is used from that value onwards.

The special cases follow from the value of \(d\):

Shape parameter Function Value at the inflection point
\(d=1\) Logistic, \(a/\left(1+e^{-b(x-c)}\right)\) \(a/2\)
\(d\to0\) Gompertz, \(a\exp\left(-e^{-b(x-c)}\right)\) \(a/e\approx0.37\,a\)
\(d=-1/3\) Generalised von Bertalanffy with an exponent of 3 \(8a/27\approx0.30\,a\)
\(d=-1\) Saturating exponential, \(a\left(1-e^{-b(x-c)}\right)\) 0 (no inflection point)

The cases \(d=1\) and \(d=-1\) are found by substituting the value in the formula. For the Gompertz function we use the limit that defines the exponential function, \((1+du)^{1/d}\to e^{u}\) as \(d\to0\). For \(d=-1/3\) the function is \(a\left(1-\tfrac{1}{3}u\right)^{3}\), and since \(\tfrac{1}{3}e^{-b(x-c)}=e^{-b(x-c')}\) with \(c'=c-\log 3/b\), this is the generalised von Bertalanffy function that starts at \(c'\). Note that the parameters \(a\), \(b\) and \(c\) keep their meaning along the whole family.

The chain rule, with \(du/dx=-bu\), gives

\[ f'(x)=ab\,u\,(1+du)^{-1/d-1}=\frac{b}{d}\,f(x)\left[1-\left(\frac{f(x)}{a}\right)^{d}\right], \]

where the last step uses \(1+du=\left(a/f(x)\right)^{d}\). For \(d=1\) this is the derivative of the logistic function, \(b\,f(x)\left(1-f(x)/a\right)\). Differentiating the last expression once more with the product rule:

\[ f''(x)=\frac{b}{d}\,f'(x)\left[1-(1+d)\left(\frac{f(x)}{a}\right)^{d}\right]. \]

Since \(f'(x)\) is positive, the second derivative is zero only where \(\left(f(x)/a\right)^{d}=1/(1+d)\). This happens where \(1+du=1+d\), that is, where \(u=1\) and \(x=c\). So for every \(d>-1\) the inflection point is at \(x=c\), and

\[ f(c)=a\,(1+d)^{-1/d}, \qquad f'(c)=ab\,(1+d)^{-1/d-1}. \]

The shape parameter therefore decides at which fraction of the asymptote the function is steepest: the fraction increases with \(d\), from zero at \(d=-1\) through one half at \(d=1\) towards one for large \(d\). As for the other exponents of this group, \(d\) is hard to estimate from data.

The number of breeding pairs in a colony of seabirds follows a Richards function with \(a=200\) pairs, \(b=0.3\)/year, \(c=10\) years and \(d=2\). How large is the colony when it grows fastest, as a number of pairs and as a fraction of its final size? How fast does it grow then? Compare the fraction with that of a logistic function.

TipSolution

The colony grows fastest at the inflection point, \(x=c=10\) years. 7 Functions without a closed form

Every function of this supplement is given by a formula: for any value of \(x\) and of the parameters we can calculate \(f(x)\) directly. Such a formula is called a closed form. Some functions that are used in ecology are defined by an equation that \(f(x)\) has to satisfy, and for some of these equations no formula for the solution exists in terms of the functions that we have used here. The value of the function then has to be calculated numerically for each value of \(x\), for example by finding a root with uniroot(). This book does not use such functions, so we only name the two that are met most often.

The Rogers random-predator equation describes the number of prey that a predator eats during an experiment in which the prey that have been eaten are not replaced, so that their density declines while the experiment runs (Rogers 1972; Juliano 1993). It starts from the same assumptions as the disc equation, but the number of prey eaten appears on both sides of the resulting equation and cannot be isolated. Its solution can be written with a special function, the Lambert W function (Corless et al. 1996).

The theta-logistic model generalises the model of population growth that leads to the logistic function: the growth rate per individual declines with the density of the population raised to a power \(\theta\) (Nelder 1961; Richards 1959; Thomas et al. 1980; Sibly et al. 2005). It is defined by an equation for the growth rate of the population, it is usually solved numerically, and it is often listed among the functions without a closed form. It does have one: the derivative of the Richards function, \(f'(x)=(b/d)\,f(x)\left[1-(f(x)/a)^{d}\right]\), is this model with a carrying capacity \(a\), a growth rate \(b/d\) and an exponent \(\theta=d\), so the Richards function is its solution.
